# 评分标准 v1.0.0

- 事实准确与完整：20分。
- 原意与逻辑：15分。
- 连贯性：10分。
- 作者声音：10分。
- 情绪适配：10分。
- 真实感：10分。
- 活人感与自然度：10分。
- 符号与标点：5分。
- 信息清晰与密度：5分。
- 修改克制与任务遵循：5分。

每维先打0—4整数等级，按rubric/v1.json权重换算。每维必须附证据；满分也需说明保护或改善了什么，不奖励无必要修改。先计算未舍入均值，再显示两位小数；小数不是测量精度或显著性保证。

## 维度边界

事实看内容是否有来源与是否完整；原意看观点、因果和确定程度；连贯性看指代、句段衔接和推进。作者声音看是否仍像原作者，情绪看强度和场景是否合适，活人感看表达是否有目的、有语境、自然。冷静教程不需要口癖或煽情。

真实感看具体表达是否有支撑、分寸是否恰当，不以看起来像亲历判断真假。编造细节仍触发事实硬伤。标点看功能与误用，不按引号、破折号或Emoji数量直接扣分。清晰度看阅读负担；修改克制看是否需要动以及是否遵守约束。

同一问题指定主要扣分维度。多个维度受损须分别写明影响，禁止机械重复扣分。严重错误用fabrication、critical_omission、meaning_reversal独立标记并附证据；不能被文风分抵消。任务需要摘要或省略时，必须在生成前声明允许删除项，不得事后放宽。

## 附加指标与胜负

总分、严重错误率、各维均分与标准差按语言分别展示。先审严重错误，再比较同一批案例的成对分差和胜平负。低错误率不保证读起来好，高总分也不抹去硬伤。首版汇总不做显著性声明、不自动宣布冠军。

正式对比建议每例每条件3轮；原文、普通指令、各Skill使用同一模型、材料、预算和参数。需要人工匿名评审，并另行按案例聚类估计分差置信区间；仅重复采样同一案例不能视作新增独立案例。模型评审与人工评审分开运行，不能混算。

后续分场景补正常文本误改率、长文一致性、重复去味漂移、素材不足处理；成本与失败率单列，不纳入文风总分。首版尚未实现自动置信区间和二次改写实验。
