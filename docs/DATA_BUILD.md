# 中文数据建设记录

## 实际收录

C-ReD全部50个CSV实际解析109204条，去除空白后精确去重109192条。其README自报128610条，与本次冻结文件不一致；这里以实际解析为准，不推断差异原因。Fast-DetectGPT的24个原始数据文件包含15700个文本条目（original与sampled各7850），精确去重15124条；同时保留24个参数文件。二者按用户明确授权私有归档，许可不确定性仍记录在sources.json中，不推断公开再分发授权。

另完整保留Slopkit两套写作基准的JSONL及说明，教学示例和供应方旧评分另存，不冒充本轮参赛成绩。公开规则/示例、原始检测数据与已整理改写案例三层分开统计。

## 中文500条的产生方式

原文全部选自冻结的C-ReD CSV；只去除首尾空白，没有用模板改词或复制变体凑数。覆盖5个领域、多个来源生成者，标签来自上游，不作为质量证明。按原主题及original_id排除同源变体，先做候选分层，再标注与审核。代码可用tools/select_candidates.py重建首轮500候选；候选不等于最终通过名单。

首批100候选用于合同校准：74通过、18淘汰、8个标点合同整体升级。发现人类来源文本也有病句、残缺和重复，故增加完整句界筛选，优先补充独立短新闻与摘要作为no_edit候选；不放宽验收标准。标点类按保护和修复两种任务统一重建v2，避免仅因标点正确就淘汰。

最终按预设类别配额选择500条：套话80、无需修改80、事实100、声音情绪70、标点40、连贯性50、缺素材40、长文40。优先保留初始通过案例，缺额从通过审核的备用池按ID的SHA256排序补位；不按任何参赛Skill的胜负挑题。各类按60%/40%组成开发300和验收200，同源主题不跨区。验收集未参与Skill调优；不保证未出现在模型预训练数据中。当前没有运行新PK。

## 合同与审核

每例提供任务、受众、原文、可用材料、核心保护点、连续原文引文、作者声音、允许修改范围、失败条件及评分提醒。checks是重点而非穷尽事实；数字字串仅作线索，同义改写不能凭字串缺失判错。

请求gpt-6-astra、medium进行初标，再以独立上下文复核；两次用的是同一请求模型，不是两个不同模型，也没有人工逐条终审。模型输出、复核、提示版本与用量存于data/curation；原始运行事件只在本地归档，不入仓库。早期少数复核重复执行，保留初次记录；若有分歧按否决结论处理，不挑选更有利的审核结果。

主助手抽读时进一步明确标点等效性：整个标点类别统一追加“符号变化本身不扣分，只有实际语义、关系或功能损失才判错”的解释。保留上游标注原件与此解释，不把必须保留某个符号当作普遍规则。该解释写入任务、失败条件和评分提醒，适用于所有参赛者。

程序逐例核对CSV记录、正文SHA256、保护点引文与声音引文；精确去重后用中文五字片段Jaccard检查，阈值为0.30。阈值下没有命中不代表不存在语义近似；详情见data/curated/audit.json。

## 限制

这是一版模型辅助整理、可追溯的评测集，不是人工金标准。500条来自同一个上游集合，新闻和问答较多，不能代表全部公众号文体；40条长文按原文字符数至少1200筛选，不代表覆盖超长文章。原文事实未外部核实，任务验收的是来源忠实性；矛盾或缺料导致无法建立合同的候选被隔离。

正式对外宣称胜负前，应增加人工匿名复核、真实授权拒稿以及更长公众号文章，并报告重复运行波动。原始资料库很大不等于有效评测样本同样多。
